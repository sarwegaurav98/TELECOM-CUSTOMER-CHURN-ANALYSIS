# TELECOM-CUSTOMER-CHURN-ANALYSIS
This project analyzes the IBM Telco Customer Churn dataset (7,032 records) using R to identify key drivers of customer attrition. It features data cleaning, statistical hypothesis testing (Chi-Square, Cramer’s V), predictive modeling via Logistic Regression (AUC: 0.856) and Decision Trees, and K-Means customer segmentation (k=3).
